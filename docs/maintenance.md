# Как обновлять pasha.lt

## Где что лежит

| Что | Файл |
|---|---|
| Даты, расписание, адрес, телефон, список страниц | `data/site.json` |
| Все подписи и шаблоны текстов на 6 языках | `data/i18n.json` |
| Пасхалия, режимы сайта, отрисовка блоков | `js/pascha-core.js` |
| Пересчёт режима и таймер в браузере | `js/pascha-runtime.js` |
| Сборка HTML, sitemap, данных для браузера | `tools/build.mjs` |
| Тексты статей (только русский) | `ru/*.html` — вне блоков `<!-- @region … -->` |
| Источники цитат | `docs/content-sources.md` |
| Пасхальное приветствие на разных языках | `data/site.json → greetings` |
| Пасхальный круг (переходящие дни и их смещение от Пасхи) | `data/site.json → calendar.cycle`, названия — `data/i18n.json → <язык>.cycle.feasts` |
| Стили (цвета, шрифты, компоненты) | `css/style.css` — токены в начале файла |
| Шрифты | `fonts/` — Spectral и Manrope (лицензия OFL), подмножество латиница + кириллица |

Файлы `lt/`, `en/`, `pl/`, `ukr/`, `de/index.html`, корневой `index.html`, `sitemap.xml` и `js/data/*` **генерируются целиком** — правьте не их, а `data/*.json`.
В русских страницах сборка переписывает только содержимое между `<!-- @region имя -->` и `<!-- @/region имя -->`; остальной текст правится вручную.

## Ежегодный порядок

1. **Дату Пасхи вводить не нужно** — она вычисляется (юлианская пасхалия, 2020–2099). На всякий случай её можно сверить с церковным календарём; при расхождении — `calendar.paschaOverrides`, например `"2031": "2031-04-13"`.
2. **Когда приход утвердил расписание**, в `data/site.json → schedules` поставьте:
   ```json
   "2027": { "status": "confirmed", "template": "standard", "source": "Утверждено настоятелем 01.03.2027" }
   ```
   Пока стоит `"pending"` (или года нет вовсе), сайт пишет «Расписание уточняется» и прошлогоднее время не показывает.
3. **Если в этом году что-то иначе**, добавьте в запись года `exceptions` — ключ `тип@группа`:
   ```json
   "exceptions": {
     "typika@sunday": { "time": "10:00" },
     "food_blessing@saturday": { "time": "12:00", "until": "18:00" }
   }
   ```
   Пропустить пункт: `{ "skip": true }`. Полностью своё расписание: `"items": [ … ]` вместо `"template"` (формат — как в `scheduleTemplates.standard`).
4. **Пересоберите и проверьте**:
   ```
   node tools/build.mjs
   node --test tools/tests/*.test.mjs
   node tools/check-site.mjs
   ```
5. Загрузите изменённые файлы на хостинг, как раньше.

## Режимы сайта

| Режим | Когда | Что видно |
|---|---|---|
| A — подготовка | от Чистого понедельника (Пасха − 48 дней, `invitationStartDaysBefore`) до начала службы | Приглашение, дата, обратный отсчёт (до службы, если расписание утверждено, иначе до дня Пасхи), расписание или «уточняется» |
| B — пасхальные дни | от начала ночной службы до конца дня Отдания (Пасха + 38 дней) | «Христос Воскресе!», без отсчёта; расписание дня Пасхи до полуночи воскресенья |
| C — остальное время | после Отдания и до начала периода A | Дата следующей православной Пасхи, «расписание будет опубликовано» |

Часовой пояс — Europe/Vilnius, переходы на летнее время учитываются.

## Почему нужна пересборка и что будет без неё

HTML собирается на дату сборки, поэтому он верен и без JavaScript. Браузер затем пересчитывает режим на текущую дату тем же кодом — посетители с JavaScript видят актуальное состояние, даже если сайт давно не пересобирали.
Без JavaScript (поисковики, превью в мессенджерах) виден текст на момент последней сборки. Он сформулирован с полными датами и не приглашает на прошедшее как на будущее, но **пересобирайте сайт хотя бы при смене режима**: после утверждения расписания, после Пасхи и после Отдания. Автоматическую пересборку по расписанию можно настроить позже, когда будет понятно, как публикуется сайт.

## Локальный просмотр

```
node tools/build.mjs
python3 -m http.server 8765
```
Откройте http://localhost:8765/ru/ (VS Code Live Server тоже подойдёт — ссылки от корня сайта).

Проверить любой момент времени, не меняя часы компьютера:
- в браузере: `http://localhost:8765/ru/?date=2027-05-01T23:29:50%2B03:00` (параметр влияет только на эту вкладку);
- при сборке: `node tools/build.mjs --now 2027-05-01T12:00:00+03:00 --out /tmp/pasha-test` (запись в отдельную папку; без `--out` перезапишет файлы проекта).

## Языковые версии

Полные переводы есть только у главной страницы (ru, lt, en, pl, uk, de). Статьи — только на русском; переключатель языка на них ведёт на главную выбранного языка с пояснением, hreflang для статей не выводится.
Когда появится перевод статьи: создайте файл (например `lt/velykos-prasme.html` по образцу русской страницы с теми же блоками `@region`), добавьте его в `data/site.json → pages.<id>.lt`, заголовок и описание — в `data/i18n.json → lt.pages.<id>`, пересоберите.

## Интерфейс (версия 2026-10)

- **Главный экран**: заголовок слева, панель с датой Пасхи справа. В панели — обратный отсчёт (в период подготовки), статус расписания, дата западной Пасхи (раскрывается) и кнопка «Добавить в календарь»: браузер создаёт файл `.ics` без сервера. При утверждённом расписании в календарь попадает начало ночной службы, иначе — день Пасхи.
- **Пасхальное приветствие**: фразы на 14 языках, первой идёт фраза на языке страницы. Языки сменяются сами, пока блок виден; есть пауза и выбор языка. Без JavaScript показывается весь список.
- **Пасхальный круг**: начало Великого поста, Вход Господень в Иерусалим, Пасха, Радоница, Отдание, Вознесение, Троица. Даты вычисляются от Пасхи; ближайший день отмечен. После Троицы показывается круг следующего года.
- **Порядок пасхальной ночи** и **список статей со временем чтения** (время считается при сборке) — на русской главной.
- **Статьи**: время чтения, кнопка «Поделиться» (системное меню телефона или копирование ссылки), полоса прогресса чтения в шапке (в браузерах с поддержкой `animation-timeline`).
- **Телефон**: после первого экрана снизу появляется панель «Расписание · Как добраться · Позвонить».
- Языки на компьютере — выпадающий список в шапке; в мобильном меню — сетка из шести кнопок.
- Шрифты размещены на самом сайте: запросов к Google Fonts нет.
